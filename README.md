# المحاسب | Muhasib

**نظام محاسبي سحابي باللغة العربية للمحلات والشركات الصغيرة والمتوسطة في السعودية**

A cloud-based Arabic accounting & POS system for small and medium businesses in Saudi Arabia.

---

## ✨ المميزات

### المبيعات والمشتريات
- فواتير مبيعات ومشتريات مع حساب ضريبة القيمة المضافة
- سندات قبض وسندات صرف
- إمكانية البيع بالسالب عند نفاد المخزون (حسب إعداد المنشأة)

### نقطة البيع (POS)
- شاشة كاشير مخصصة للبقالات والسوبرماركت
- فتح وإغلاق وردية الكاشير مع جرد النقدية
- طباعة الإيصال على الطابعة الحرارية 80mm أو على ورق A4

### الأصناف والمخزون
- إدارة الأصناف مع وحدة افتراضية (حبة)
- تتبع الأصناف بالدفعات وتاريخ الانتهاء أو بالرقم التسلسلي

### المستخدمون والأمان
- تسجيل دخول متعدد المستخدمين
- قاعدة بيانات مستقلة لكل عميل، وبياناته متاحة له من أي جهاز
- صلاحيات المستخدمين يديرها مالك النظام

### نسختان من النظام
- **نسخة سحابية:** تعمل على خادم Node.js مع قاعدة بيانات SQL Server
- **نسخة تعمل دون إنترنت (PWA):** قابلة للتثبيت على الجوال والكمبيوتر، وتُحفظ بياناتها في المتصفح
